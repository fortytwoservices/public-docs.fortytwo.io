# Enable your Universe

# Step 1 - Grant admin consents

As documented under [grant admin consents](../index.md#admin-consent), the following applications are required for the JML process:

- [Fortytwo Universe](https://login.microsoftonline.com/common/adminconsent?client_id=2808f963-7bba-4e66-9eee-82d0b178f408)
- [Fortytwo Universe - Portal](https://login.microsoftonline.com/common/adminconsent?client_id=d5151be7-b1d6-411d-88f1-b1da1350211f)
- [Fortytwo Universe - Entra ID Connector](https://login.microsoftonline.com/common/adminconsent?client_id=2fcb40bf-98fd-499c-b47f-935aaa071984)
- [Fortytwo Universe - Workflows](https://login.microsoftonline.com/common/adminconsent?client_id=a215ca40-216b-49aa-ac23-f5256a8d6555)

# Step 2 - Grant admin roles

In order to get access to Fortytwo Universe, you need a set of roles assigned. Please check out [role descriptions](../permissions/index.md#user-roles) and [how to assign them](../permissions/index.md#how-to-assign) in order to assign the following required roles for configuring JML:

| Role | Required because |
|-|-|
| Bytt.Email - administrator | Required in order to configure email and account name patterns |
| Collections - Administrator | Required in order to configure collections for targeting user provisioning |
| Events - administrator | Required in order to read audit log |
| IAM Core - administrator | Required in order to configure connectors and sync rules |
| Workflow - administrator | Required for connecting notifications etc. for the JML process |
