# Implementing Joiner-Mover-Leaver

This set of sub pages contain an approach to implementing the Joiner-Mover-Leaver (JML) process for your organization, where you can do essentially everything yourself, or if you want - ask your Fortytwo contact for help and guidance.

- Enable your Universe
    - Grant admin consent
    - Grant admin roles
    - Enable evaluation license through Azure Marketplace
- Configure connectors
- Join existing user accounts
- Enable attribute synces
- Enable user life cycle management
- Enable JML workflows
