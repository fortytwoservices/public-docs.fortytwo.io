# Get started

## Admin consent to Fortytwo Universe

Admin consent must be granted to work with Identity Universe. This can be achieved by a Global Admin by following and accepting the Microsoft admin consent flow on behalf of your organisation.

This is required to gain the necessary authorisation when working with the Identity Universe API.

The link includes the Fortytwo Universe application identifier and will grant admin consent in the home tenant of (admin) user.

[https://login.microsoftonline.com/common/adminconsent?client_id=2808f963-7bba-4e66-9eee-82d0b178f408](https://login.microsoftonline.com/common/adminconsent?client_id=2808f963-7bba-4e66-9eee-82d0b178f408)
