# Change email

This is for the feature inside Identity Universe. For the managed service, see [Bytt.Email](../../managed-identity-services/Bytt.Email/index.md).

Change Email allows end users to change their own email address and UPN, both in Entra ID and Active Directory. This enables self-service of these attributes when a name is changed at a time convenient to the user. It also tracks previously used email addresses to ensure an email address isn't reused within a defined period. The history allows a user who has been away and no longer has an account to get back a reserved email address.

The Change email feature is enabled seperately from Identity Universe. Please contact Fortytwo before you start to have it enabled.
