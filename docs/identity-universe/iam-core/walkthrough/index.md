# Overview

In the walkthrough, we will set up the configuration for a fictitious company. We hope this gives you an idea of how everything fits together and what a working system would look like. We will walk through all the steps, and this is intended as a step-by-step guide to building your own test environment and learning how it works.

Before you begin, make sure you have granted Identity Universe access to your [tenant](../../get-started/index.md) and have granted your admin account all [necessary permissions](../../get-started/permissions/index.md).

Our company has an HR system that is not on the list with preconfigured connectors. We will therefore build our own using PowerShell and the published API. We will then connect the Entra Connector to read all existing users. We will create sync rules to get all these objects into the Universe.

There are also Walkthrough sections for other sections; these build on this section have been completed.
