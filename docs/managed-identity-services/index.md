# Managed Identity Services

Welcome to Fortytwo Managed Identity Services. Here you will find documentation material related to our identity services.

## Available Services

::::cards{cols=2}
:::card{title="Verified ID" icon="badge-check" href="verified-id/index.md"}
Enterprise-grade Microsoft Entra Verified ID implementation delivered as a managed proxy service. Includes support for multiple credential types, optional CheckID frontend integration, and white-label customization options.
:::
:::card{title="Fortytwo Managed Microsoft Entra External ID" icon="users" href="./external-id/index.md"}
A production-ready, enterprise-grade implementation of Microsoft Entra External ID for customer identity and access management (CIAM), delivered as a fully managed service.
:::
:::card{title="Bytt.Email" icon="mail" href="./Bytt.Email/index.md"}
Allows end users to change their own email address and UPN, both in Entra ID and Active Directory, based on predefined patterns.
:::
:::card{title="HR Provisioning" icon="user-plus" href="./hr-provisioning/service-description.md"}
Designed to streamline and automate the synchronization of HR data with the identity platform through the Entra ID Inbound Provisioning API.
:::
:::card{title="Entra ID Advanced Criteria Groups" icon="filter" href="./entraid-advanced-criteria-groups/index.md"}
A simple open source solution that enables you to build as advanced scenarios as you'd like.
:::
:::card{title="Organizational Structure Groups" icon="network" href="./organizational-structure-groups/security-groups/service-description.md"}
Designed to streamline and automate the synchronization of the HR organizational structure / hierarchy into an Entra ID security group structure.
:::
::::
