# What is CheckID?

CheckID helps organizations onboard users into Microsoft Entra ID securely, quickly, and with less IT overhead.

## What CheckID Solves

- Reduces first sign-in friction for new hires and returning users
- Replaces insecure/manual temporary-password workflows
- Supports Zero Trust onboarding patterns with Entra ID
- Helps bootstrap passwordless and phishing-resistant journeys

## Core Capabilities

::::cards{cols=2}
:::card{title="Identity Verification and Account Claiming" icon="fingerprint"}
Users authenticate with supported national or banking identity providers, then select the account they should onboard.
:::
:::card{title="Temporary Access Pass (TAP) Bootstrap" icon="key-round"}
CheckID generates a TAP and guides the user through Microsoft Authenticator setup so the account is ready for modern authentication.
:::
:::card{title="Passkey-First Onboarding" icon="key"}
Users can register passkey-capable authentication during onboarding, aligning with phishing-resistant targets.
:::
:::card{title="Optional Password Path" icon="lock"}
For hybrid or legacy dependencies, CheckID can support password setup with policy checks and optional password agent integration.
:::
:::card{title="Custom Security Attributes Support" icon="tags"}
CheckID can read and use custom security attributes.
:::
:::card{title="Time Stamping" icon="clock"}
CheckID can write a timestamp to a configured custom security attribute when an account is claimed or reset, giving identity teams better lifecycle visibility and lightweight auditability.
:::
:::card{title="Branding and Domain Customization" icon="palette"}
Organizations can customize domain, logo, text, and styling for a consistent user experience.
:::
::::

## Supported Use Cases

- New employee first-time access
- Returning employee re-onboarding
- Passwordless rollout
- High-security environments with Conditional Access constraints
- Hybrid environments that still require password support

## Who Uses This

- Identity and Access administrators
- Security architects
- Endpoint/Workplace teams
- IT onboarding/helpdesk teams
