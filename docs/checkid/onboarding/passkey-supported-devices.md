# Passkey Supported Devices

Passkeys are supported on modern phones, tablets and computers with a recent operating system. The table below reflects Passkeys stored in Microsoft Authenticator.

| Device Type | Supported From |
| -- | -- |
| iPhone | iOS 17 and newer |
| iPad | iPadOS 17 and newer |
| Mac | macOS Ventura (13) and newer |
| Android Phone | Android 14 and newer |
| Windows PC | Windows 10 and newer |
