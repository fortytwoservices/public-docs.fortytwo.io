## Overview

This guide details how to grant yourself access to an Azure Kubernetes Service (AKS) cluster using Azure RBAC roles in the Azure portal.

## Prerequisites

- Successful deployment of the managed application.
- Required account privileges to grant resource access

## Grant access to users

::::steps
### Log into Azure Portal

Go to [Azure Portal](https://portal.azure.com/) and sign in.

### Navigate to Your AKS Cluster

1. Click `Go to resource` and click the managed resource group (eg. `mrg-kubernetes-xxxx` if you installed with default settings) in essentials section under `Overview`.
2. Find your Kubernetes service resource and click it.

### Access Control (IAM)

1. Click the `Access Control (IAM)` section and click on `+ Add`.
2. Select the `Azure Kubernetes Service RBAC Cluster Admin` role and click `Next`.
3. Click `Select members` and find your own user account (and any other user that needs access) in the list. Click `Select` to save the user selection.
4. Click `Next` and then `Review + Assign` to save the changes.
::::

## Conclusion

You now have the necessary permissions on your AKS cluster.
